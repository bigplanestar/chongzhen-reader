# 崇祯十年 · GitHub 书房

访问：https://bigplanestar.github.io/chongzhen-reader/

网站与加密书稿完整托管在 GitHub，不依赖家中服务器或临时隧道。使用迁移版访问密码打开书房；密码不保存在仓库。当前迁入850章及885个正文版本，全书计划1000章。

支持按卷选章、搜索、字号、字体、背景设置、阅读位置记忆，以及当前章节的 Word 下载。

修改、批准和版本恢复直接提交到本仓库。打开书房后，点击“修改”或“我的书房 → 连接 GitHub 编辑”，按页面说明连接自己的 bigplanestar 账号。仅授予 chongzhen-reader 仓库 Contents 读写权限即可。选择记住连接时，访问密钥使用书房密钥加密后保存在本浏览器；解锁后可自动恢复连接。

每次修改新增正文版本，并取消当前版本的批准；审阅记录保留。章节和目录在同一次提交中保存。不同设备同时修改时，旧页面的保存会被拒绝，输入不会被清空。其他设备点击“刷新”即可取得 GitHub 上的最新稿件。

“我的书房 → 导出全书与版本记录”下载可供离线保管、继续改写和迁移的 JSON。导出的 JSON 和 Word 是解密后的个人文件，请自行保管。

正文、标题和版本记录以 AES-256-GCM 加密保存；密码通过 PBKDF2-SHA256 派生密钥。请保管迁移版密码。原服务器的访问密码不适用于本迁移版；原服务器数据库仍保留，未删除或改写。

首次迁移采用2026年10月19日已回收并核对的850章网站快照。若原服务器存在该快照之后的修改，需要在恢复连接后另行回收合并。
